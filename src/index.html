About

cat about.md

I've been writing code since 2021. It started with scrapers, turned into Discord bots, then data tools, then the services running underneath them.

Most of what I build now is backend work and the tooling that sits under it: Discord bots that stay up, market data pipelines, a VS Code extension. Outside of that, I spend time rebuilding things that already exist, like a concurrent job queue or a TCP server from scratch, not because I need them, but because I'd rather understand how something works than just trust that it does. I'm taking on contract work alongside my computer science degree right now. If you've got something that needs building, or something that already exists and keeps breaking, I'd like to hear about it.
